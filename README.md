# Styled by S

A simple landing page for Styled by S, a Phoenix-based personal styling service.

## What is included

- One-page static website
- Services and prices
- Email/contact form wired to `styledbys.edit@gmail.com` through FormSubmit
- QR/source tracking through `?src=...`

## Local preview

Open `index.html` in a browser, or run a simple local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
